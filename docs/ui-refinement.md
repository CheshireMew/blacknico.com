# 界面精修记录

日期：2026 年 10 月 29 日。按站主要求使用本地 Impeccable 4.8.0 指南与 0.1.18 检测引擎，优化现有三个页面。

## 页面调整

首页移除大幅黑猫插画和介绍区的装饰印章，使用紧凑的标题、介绍与作品入口。在 1440px 的本地 Chrome 视口中，介绍区高约 252px，精选项目封面从页面顶部约 637px 开始出现。网站入口改为标题与域名组成的轻量列表，精选作品保留真实封面，其他项目减少边框与容器。

项目目录统一正文与标题层级，使用分栏列表。正文为 16px，输入框为 16px，主要图标按钮、筛选按钮与复制按钮的点击区域至少为 44×44px。搜索支持 `/` 聚焦、`Esc` 清空，保留原有分类、关键词链接与结果播报；更新筛选 URL 时保留其他参数和锚点。

邀请页去掉大幅星形装饰，统一优惠、邀请码与操作按钮的间距。复制操作补充处理中、成功勾选、原始按钮名称恢复，以及失败后的邀请码选中与手动复制提示。邀请码、邀请地址、优惠比例和说明均保留。

浅深主题使用统一的文字、背景、边框、强调色及成功状态颜色。首次访问跟随系统，手动选择可保存，并与其他标签页同步。减少动态效果和 Windows 强制颜色模式有对应处理。手机导航支持键盘打开、进入链接、Esc 关闭并返回按钮；关闭 JavaScript 时仍能访问页面、导航与邀请链接。

Manrope 拉丁可变字体与 Noto Sans SC 中文标题字形子集托管在 `public/fonts/`，共约 45KB，附带原始 OFL 许可证。网页不请求 Google Fonts 服务；标题新字形使用系统中文字体回退。未再使用的插画源文件保留在原处。

## 验证范围与结果

- `npm run check`：39 个项目、5 个子站、3 篇文章、4 个邀请地址、5 个邀请码，以及标题、分享信息、结构化数据、站点地图与 404 检查通过。
- `npm run build`：生成可部署的静态页面与资源，不生成压缩包。
- `node scripts/qa-browser.mjs`：Windows 本机 Chrome，通过 1440、1100、901、900、768、700、390、320px 八种宽度的布局检查，以及搜索、筛选、剪贴板、失败恢复、系统主题、存储受限、键盘导航和禁用 JavaScript 的场景；无脚本错误。
- axe-core 4.10.3：三个页面 × 浅深主题 × 1440/390px，共 12 组自动检查，未发现所检查规则的违规项。
- Impeccable：对修改的渲染模板、样式、浏览器脚本及三个本地页面运行一次检测，返回 `[]`，退出码为 0。
